These three numbers can legitimately differ — each answers a different question. Check pass rate is how much of the model is compliant, check by check (one element measured against one requirement). Entity pass rate requires an entity to pass every requirement of its specification to count as passing at all. Specification pass rate goes one step further: a specification passes only if every applicable entity passes it — one failing element fails the whole specification, the way one missing handrail fails a safety inspection. For a compliance deliverable, the specification pass rate is the number that matters: “we passed 0 of 1 specifications” is the honest statement, not the higher check-level or entity-level percentage.
